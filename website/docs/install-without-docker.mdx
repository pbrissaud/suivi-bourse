This page will carry the Docker-less install: `uv sync`, a directory to keep
the store in, and a service unit if you want one.

:::info Not written yet
It is the subject of its own ticket. What it will hold:

- the runtime prerequisites, and the two directories to point the app at;
- how the boot variables change hands when their container defaults no longer apply;
- supported architectures, in one line.

It is the simplest form of the product rather than the most advanced one: there
is no stack to assemble either way.
:::
