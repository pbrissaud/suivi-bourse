---
title: Install without Docker
description: Build and run SuiviBourse from its source on a host that has no Docker
---

This page installs SuiviBourse from its source and runs it as a service. You get
the same app as the Docker image: one process, one data directory.

## What you need {#prerequisites}

| Tool | Version | Used for |
|---|---|---|
| [uv](https://docs.astral.sh/uv/) | recent | Installs Python and the backend dependencies from the lockfile |
| Python | 3.15 or later | Runs the app. uv downloads it if your system does not have it. |
| Node.js | 26 | Builds the web interface, once per install or update |
| pnpm | the version the source names | Installs the web interface's dependencies |

Node.js and pnpm are only needed to build. The running app does not use them.

## Install {#install}

1. Download the source archive of the
   [latest release](https://github.com/pbrissaud/suivi-bourse/releases/latest)
   and extract it, for example into `/opt/suivi-bourse`.
2. Go to that directory:

   ```bash
   cd /opt/suivi-bourse
   ```

3. Install the backend from the lockfile, without the development tools:

   ```bash
   uv sync --locked --no-dev
   ```

4. Enable pnpm, which the source pins to an exact version:

   ```bash
   npm install -g corepack@latest && corepack enable
   ```

5. Build the web interface:

   ```bash
   cd src/web
   pnpm install --frozen-lockfile
   pnpm build
   cd ../..
   ```

If you skip the build, the app still starts, but the browser shows
`No web UI bundle in this build` instead of the interface.

## Choose the data directory {#data-directory}

SuiviBourse keeps everything in one directory, set by `SB_STORE_DIR`. The
default is `/data`, which suits the container. On a host, choose your own:

```bash
sudo mkdir -p /var/lib/suivi-bourse
sudo chown "$USER" /var/lib/suivi-bourse
```

The app creates its files inside: the database `suivi-bourse.duckdb` and its
`.wal` file, a `logs` folder, and an `agent` folder once you use the agent.

:::warning
This directory holds your portfolio and secrets: the agent's provider key and
the access-code data. Give it to one user only, and back it up. See
[Back up and update](./backup-and-update.mdx).
:::

## Run {#run}

From the source directory:

```bash
SB_STORE_DIR=/var/lib/suivi-bourse uv run --no-dev python -m application.boot
```

Open [http://localhost:8080](http://localhost:8080). The first launch asks a few
questions. See [First steps](./first-steps.mdx).

The app listens on every network interface of the host. Set `SB_WEB_PORT` to use
another port. The other variables are on [Configuration](./configuration.mdx).

Run one process per data directory. Two processes on the same directory would
both collect prices and write to the same database.

## Keep it running {#service}

On a host with systemd:

1. Find the absolute path of uv:

   ```bash
   which uv
   ```

2. Create `/etc/systemd/system/suivi-bourse.service`. Replace the user and the
   path to uv with yours:

   ```ini title="/etc/systemd/system/suivi-bourse.service"
   [Unit]
   Description=SuiviBourse
   After=network-online.target
   Wants=network-online.target

   [Service]
   Type=simple
   User=suivi
   WorkingDirectory=/opt/suivi-bourse
   Environment=SB_STORE_DIR=/var/lib/suivi-bourse
   Environment=PYTHONUNBUFFERED=1
   ExecStart=/usr/local/bin/uv run --no-dev python -m application.boot
   Restart=always

   [Install]
   WantedBy=multi-user.target
   ```

3. Make sure that user owns the data directory:

   ```bash
   sudo chown -R suivi /var/lib/suivi-bourse
   ```

4. Start the service and enable it at boot:

   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now suivi-bourse
   ```

5. Check that it answers:

   ```bash
   curl -s http://localhost:8080/health
   ```

Read the logs with `journalctl -u suivi-bourse -f`. The app stops cleanly on
`SIGTERM`, which is what `systemctl stop` sends.

## Update {#update}

1. Stop the service: `sudo systemctl stop suivi-bourse`.
2. Copy the data directory somewhere safe.
3. Extract the new release over the old source, or into a new directory.
4. Run the steps of [Install](#install) again from step 2.
5. Start the service: `sudo systemctl start suivi-bourse`.

A build from source shows no version number in the app, and it does not check
for new releases. Watch the
[releases page](https://github.com/pbrissaud/suivi-bourse/releases) instead.

## Supported platforms {#platforms}

SuiviBourse runs on any system and processor for which Python 3.15 and DuckDB
publish packages, such as Linux and macOS. The systemd steps apply to Linux. On
another system, run the same command with its own service manager.

The Docker image covers `linux/amd64` and `linux/arm64`. See
[Install with Docker](./get-started.mdx).
