---
title: Install with Docker
description: Start SuiviBourse in one container and open it in your browser
---

SuiviBourse runs as a single container. It needs Docker and one volume. There
is no database to install and no configuration file.

The image is published for `linux/amd64` and `linux/arm64`.

## Start the container {#run}

```bash
docker run -d \
  --name suivi-bourse \
  --restart unless-stopped \
  -v suivi-bourse:/data \
  -p 8080:8080 \
  ghcr.io/pbrissaud/suivi-bourse:5
```

| Option | What it does |
|---|---|
| `-v suivi-bourse:/data` | Keeps your portfolio in a Docker volume. Without it, your data is deleted with the container. |
| `-p 8080:8080` | Publishes the app on port 8080 of the host. |
| `--restart unless-stopped` | Restarts the container after a reboot or a crash. |

The same image is on Docker Hub as `paulbrissaud/suivi-bourse`.

| Tag | What you get |
|---|---|
| `5` | The latest 5.x release |
| `5.3` | The latest 5.3.x release |
| `5.3.0` | Exactly that release |

### With Docker Compose {#compose}

```yaml
services:
  suivi-bourse:
    image: ghcr.io/pbrissaud/suivi-bourse:5
    restart: unless-stopped
    ports:
      - "8080:8080"
    volumes:
      - suivi-bourse:/data

volumes:
  suivi-bourse:
```

```bash
docker compose up -d
```

## Open the app {#open}

Go to [http://localhost:8080](http://localhost:8080).

On a new installation, the app asks a few questions, starting with the currency
your figures are reported in.

![The first-launch screen asking which currency you keep your accounts in](/img/app/en/first-run-currency.png)

[First steps](./first-steps.mdx) walks you through these questions and your
first events.

## Protect the app {#protect}

:::warning
A new installation has no access code. Anyone who can reach port 8080 can read
and change your portfolio.
:::

Do one of these before you expose the app beyond your own machine:

- Set an access code in the app. See [Secure access](./secure-access.mdx).
- Publish the port on the local interface only: `-p 127.0.0.1:8080:8080`.
- Put the app behind a reverse proxy or a VPN. See
  [Configuration](./configuration.mdx#reverse-proxy).

## Check that it runs {#health}

```bash
docker ps --filter name=suivi-bourse
```

The `STATUS` column shows `healthy` about 30 seconds after the start.

For more detail, ask the app:

```bash
curl -s http://localhost:8080/health
```

```json
{
  "status": "ok",
  "now": "2026-11-14T15:00:00+00:00",
  "scheduler_running": true,
  "jobs": {
    "scrape": {"status": "ok", "verdict": "open", "...": "..."},
    "backfill": {"status": "ok", "verdict": "complete", "...": "..."},
    "performance": {"status": "ok", "verdict": "ran", "...": "..."}
  }
}
```

| `status` | Meaning |
|---|---|
| `ok` | Every job ran and nothing needs your attention. |
| `attention` | A job failed or a price has stopped updating. The **System** page of the app says which. |
| `unknown` | The app has started and no job has run yet. |

The HTTP code is `200` while the app is serving, whatever the `status`. It is
`503` only when the app cannot open its store.

The [System page](./system.mdx) shows the same information in the app, and
lists every verdict of each job.

## Update {#update}

```bash
docker pull ghcr.io/pbrissaud/suivi-bourse:5
docker rm -f suivi-bourse
```

Then run the `docker run` command from [Start the container](#run) again. Your
data stays in the `suivi-bourse` volume.

With Docker Compose:

```bash
docker compose pull && docker compose up -d
```

Back up your data before a major update. See
[Back up and update](./backup-and-update.mdx).
