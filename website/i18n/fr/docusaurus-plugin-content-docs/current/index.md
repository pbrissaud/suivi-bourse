# SuiviBourse {#suivibourse}

SuiviBourse suit votre portefeuille boursier, hébergé chez vous. Vous
enregistrez ce que vous achetez, vendez, recevez et versez, et il récupère les
cours, valorise vos positions et calcule vos rendements dans une seule devise.
Il tourne dans un seul conteneur, sur votre propre machine.

![Le tableau de bord, avec la valeur du portefeuille, son graphique et le rythme d’investissement](/img/app/fr/dashboard.png)
